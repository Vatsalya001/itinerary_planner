# P1 verification — 14 November 2026

## Implemented and verified

- Explicit clock ranges take precedence over conflicting model time fields.
- Next Saturday resolves in the destination timezone and excludes today. Negated next-Saturday wording does not activate that behavior.
- Existing expired-Saturday rollover remains in place.
- Same-day start adjustments disclose the original window. UI and exports label the effective planning window.
- Requests identifying start/end travel receive a visible disclosure that only inter-stop travel is estimated.
- A requested indoor rain backup receives a validator warning when an outdoor stop lacks one. Existing alternative-route validation checks substitutions against timing, cost and constraints.
