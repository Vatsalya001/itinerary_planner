# Demo script under two minutes

0:00–0:20 — Open the public app and show the six input fields using the prefilled Bangalore example.

0:20–0:45 — Generate a plan. Expand the trace and point out the actual searches, submission and deterministic validation.

0:45–1:10 — Show the timeline, fit explanations, estimated cost including transfers, time budget, dietary evidence and provenance. Explain that the model chooses options while code owns the facts and checks.

1:10–1:30 — Try a vague request and answer the clarification, or show an impossible-budget response. Explain the labelled deterministic fallback for provider outages.

1:30–1:50 — Open Evals. Distinguish the 32 offline workflow cases, the 26 deterministic cases and the partial real-model smoke test, including its rate-limit failure.

1:50–2:00 — Point to the README/source and state the current city coverage and estimate limitations.
